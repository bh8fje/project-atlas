# 版本与回退规范

Project Atlas 使用带备注的 Git 标签标记可回退里程碑。

## 标签规则

- 标签采用 `v主版本.次版本.修订版本` 格式。
- 每个完成版本使用 annotated tag，不使用无备注的 lightweight tag。
- 标签备注必须包含关联 Task、完成范围、测试结果和明确排除项。
- 提交与标签必须同时推送到 GitHub 和群晖，并分别核对目标提交。
- 已发布标签不可移动或复用；需要修正时创建新版本。

## 安全回退

查看某个版本而不改动当前分支：

```bash
git switch --detach v0.2.0
```

从旧版本创建独立恢复分支：

```bash
git switch -c restore/v0.2.0 v0.2.0
```

恢复分支不会覆盖当前 `main`。除非用户明确要求并确认影响，不使用破坏性的强制回退。
