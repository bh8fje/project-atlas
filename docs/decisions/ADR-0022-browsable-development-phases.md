# ADR-0022：可查看详情的建设阶段

- 状态：Accepted
- 日期：2026-08-23
- 关联任务：TASK-023

## 背景

Dashboard 的“建设进度”只展示阶段名称和完成状态，用户无法直接了解每个阶段已经实现了哪些功能。

## 决定

将八个建设阶段改为可展开的列表。每个阶段包含专业、清晰的名称、一句说明和三个已实现功能点。列表使用标准按钮和展开状态，支持鼠标、触控和键盘操作。

阶段详情仍是代码中的本地静态资料，不读取网络、数据库或 Git 历史。

## 后果

- 用户可以从建设进度直接查看每个阶段的实现范围。
- 阶段名称作为稳定的专业分类，不使用过度口语化表达。
- 四种语言需同时维护阶段说明与功能点。
