# ADR-0023：Dashboard 信息含义与真实性边界

- 状态：Accepted
- 日期：2026-08-23
- 关联任务：TASK-024

## 背景

Dashboard 曾将项目组成示意标记为“项目关系”，并以“100%”、“一切运行稳定”等形式展示静态发布数据。这会让用户误以为系统已完成实时项目扫描、关系分析或运行监控。

## 决定

Dashboard 明确区分项目建设、发布记录、项目组成和受控操作。组成图的每条连接必须标注具体含义，并明确声明其不是自动扫描或实时分析结果。

静态测试数、版本号和文件状态统一归类为发布记录。在没有真实时序数据和计算规则前，不展示健康分数或实时运行结论。

## 后果

- 用户可以理解项目组成图中的节点和连接含义。
- Dashboard 展示的能力与当前数据来源保持一致。
- 未来真实的多项目关系视图必须由独立任务接入核心数据，不复用当前的项目组成示意。
