# ADR-0012：构建有界、可追踪且脱敏的 AI 上下文

- 状态：Accepted
- 日期：2026-08-23
- Task：TASK-013

## 背景

AI 理解能力需要把本地知识转换为模型可消费的上下文。如果直接发送完整记录，可能超出模型限制，也可能把密码、令牌等敏感字段暴露给外部提供方。上下文必须在任何 AI 调用之前形成明确的本地控制边界。

## 决策

建立 `AIContext` 与 `AIContextBuilder`：

- 调用者显式提供 Project ID、知识记录和最大字符数。
- 记录按时间、类型和 ID 确定性排序。
- 上下文保留每条来源的“记录类型 + 记录 ID”，便于追踪。
- 对名称以 password、token、secret、api key、private key、credential 或 authorization 结尾的 JSON 字段进行递归脱敏。
- 超出字符上限时停止添加内容、标记 `truncated` 并写入明确截断标记。
- 允许无 Project ID 的全局记录，拒绝混入其他 Project 的记录。

## 边界

- 不调用任何 AI 模型或网络服务。
- 不读取文件系统或数据库；只处理调用者提供的 `KnowledgeRecord`。
- 脱敏是基于字段名的防护，不保证识别任意自由文本中的秘密。
- 不做摘要、推理、向量化、优先级判断或 Token 精确计数。
- 不提供 API、Dashboard 或 UI。

## 后果

正面影响：

- AI 提供方之前存在可测试、可审计的隐私与大小边界。
- 上下文来源明确，后续分析结果可以保留溯源信息。
- 构建过程完全本地、确定且与具体模型供应商解耦。

限制：

- 字符上限不等于具体模型的 Token 上限。
- 自由文本中没有敏感字段名的秘密可能无法自动识别。
- 截断不进行语义完整性优化。
