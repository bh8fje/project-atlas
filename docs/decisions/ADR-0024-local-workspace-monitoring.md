# ADR-0024：通过本机服务管理项目目录并定时检查变化

- 状态：Accepted
- 日期：2026-08-23
- 关联任务：TASK-025

## 背景

Project Atlas 已具备项目发现、结构分析和结构指纹能力，但本地 Dashboard 过去只能展示发布记录。浏览器不能安全、持续地读取用户任意选择的本机目录，因此仅靠前端页面无法完成目录选择和后续检查。

## 决定

增加一个只监听本机回环地址的轻量服务，由它协调以下操作：

1. 通过操作系统目录选择器取得用户明确选择的目录，选择器提示跟随当前界面语言。
2. 将已批准目录及检查设置保存在本机 JSON 文件中。
3. 复用现有项目发现、结构分析和结构指纹能力执行首次检查与后续检查。
4. 只有用户明确开启后，才在本机服务运行期间按设定间隔检查变化。
5. Dashboard 只连接固定的本机地址，并显示最近一次检查时间、项目数量和新增、变化、移除摘要。

本功能不采用持续文件监听，也不安装常驻系统服务。关闭本机服务后，自动检查立即停止。

## 安全边界

- 服务默认且只允许监听 `127.0.0.1` 或 `localhost`。
- 浏览器请求只接受 Project Atlas 本地 Dashboard 的明确来源。
- 目录选择必须由用户在系统选择器中完成，接口不接受网页直接提交任意路径。
- 检查只读取目录条目和文件元数据，不读取文件内容、Git 历史或凭据。
- 移除目录只删除 Project Atlas 的登记信息和检查记录，不修改或删除用户项目文件。
- 路径、结构指纹和检查结果不发送到外部网络。

## 后果

用户现在可以在 Dashboard 中管理扫描目录，并在本机服务运行时获得可追踪的定时检查结果。代价是使用该功能时必须同时运行 Dashboard 与本机服务；未来若需要系统启动后常驻、原生文件监听或通知，必须另立 Task 和安全决策。
