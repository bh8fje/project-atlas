# ADR-0020：本机语言偏好与系统语言跟随

- 状态：Accepted
- 日期：2026-08-23
- 关联任务：TASK-021

## 背景

Project Atlas Dashboard 需要支持中文、英语、俄语和韩语。用户尚未表达偏好时，界面应尊重操作系统语言；一旦用户明确选择，选择应在后续本机访问中保持。

## 决定

Dashboard 使用内置的类型化翻译字典提供 `zh`、`en`、`ru`、`ko` 四种语言。初始偏好为 `system`，按浏览器语言列表选择第一个受支持的基础语言，无法匹配时回退英语，并监听系统语言变化。

用户可以在界面中选择“跟随系统”或任一支持语言。显式语言使用 `localStorage` 保存在当前浏览器；选择“跟随系统”会删除该记录。当前语言同步到文档 `lang` 属性。

## 后果

- 语言切换即时完成，不需要刷新或网络请求。
- 偏好不进入 SQLite、云端、账号或 Git，不跨浏览器同步。
- 禁用浏览器存储时，本次会话选择仍生效，但刷新后恢复跟随系统。
- 新增语言必须扩展同一类型化数据契约并补充测试。
