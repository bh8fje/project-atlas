# ADR-0018：确定性的多项目智能聚合

- 状态：Accepted
- 日期：2026-08-23
- 关联任务：TASK-019

## 背景

单项目理解无法回答组合层面的共同风险、连接密度和孤立项目问题。重新扫描项目或再次调用 AI 会增加隐式副作用、成本和不可复现性。

## 决定

建立 `MultiProjectIntelligenceService`，只接受调用者明确提供的 `Project`、每项目一份 `ProjectUnderstanding` 和项目关系图。服务验证三者的项目集合完全一致，并确定性生成项目摘要、跨项目共同风险、关系数量和孤立项目清单。

共同风险按大小写不敏感文本归并，只有出现在至少两个不同项目中的风险才进入结果。所有项目、风险、来源和孤立 ID 都稳定排序。

## 后果

- 相同输入始终产生相同组合视图，并保留理解来源。
- 服务不发现项目、不读文件、不调用 Provider、不写数据库，也不推断新关系。
- 结果质量受输入理解和显式关系图质量限制。
- 主动观察与提醒属于 TASK-020。
