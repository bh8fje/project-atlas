# ADR-0021：中文优先的浅显产品文案

- 状态：Accepted
- 日期：2026-08-23
- 关联任务：TASK-022

## 背景

Dashboard 曾直接展示“供应商无关的分析契约”等工程术语。它们适合开发文档，却不能帮助普通用户快速理解功能。多语言分别创作文案还会造成四种语言含义不一致。

## 决定

所有直接面向用户的文案先用浅显中文确定含义，再翻译成英语、俄语和韩语。中文优先说明用户看到的结果、操作方式和影响，不把内部类名、架构边界或工程术语当作功能介绍。

在翻译文件中把中文放在第一位，并通过测试阻止已知拗口表述重新进入界面。完整规则记录在 `docs/PRODUCT_LANGUAGE.md`。

## 后果

- 用户界面更容易第一次读懂。
- 四种语言以同一中文含义为准，减少表达偏差。
- 开发文档仍可使用准确技术术语，但新增产品文案必须遵循浅显表达规则。
- 文案变更需要同时更新四种语言和对应测试。
