# ADR-0015：本地只读 Dashboard

- 状态：Accepted
- 日期：2026-08-23
- 关联任务：TASK-016

## 背景

Project Atlas 已拥有项目、历史、关系与 AI 辅助结果的数据契约，但缺少一个统一、低风险的可视入口。首个界面需要表达这些已有能力，同时不得提前引入移动访问、控制操作、API 或云端依赖。

## 决定

在独立的 `dashboard/` 目录使用 Sites/Vinext 站点结构建立本地 Dashboard。页面是已有项目基线的静态只读投影，展示项目状态、里程碑历史和关系概览。

Dashboard 不配置 D1 或 R2，不读取远端数据，不保存用户操作，不调用 AI Provider，也不暴露任何凭据。Python Core 与界面保持进程和依赖边界；当前版本不建立 API 集成。

## 后果

- 用户可以通过本地开发服务器查看 Project Atlas 的统一概览。
- Dashboard 可以独立构建，且不会为 Python Core 增加运行时依赖。
- 当前数据是明确的版本基线，不代表实时采集。
- TASK-017 才负责专门的移动访问能力；TASK-018 才负责控制入口和写操作设计。
