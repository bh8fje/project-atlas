# ADR-0025：从项目识别结果进入本机项目详情

- 状态：Accepted
- 日期：2026-08-23
- 关联任务：TASK-026

## 背景

TASK-025 已能识别项目，但 Dashboard 只显示项目名称、路径和少量摘要。用户无法从项目名单继续查看 Project Atlas 已经掌握的项目结构信息，项目识别因此缺少自然的后续入口。

## 决定

将项目名称改为可点击入口，并在同一 Dashboard 中打开项目详情。详情只使用最近一次本机检查已经保存的数据，展示：

- 项目名称与路径
- 最近检查时间与变化状态
- 结构检查是否完整
- 已识别技术栈
- 按目录、源代码、文档、配置文件等分类的资产数量

超过检查上限的项目仍可打开详情，但只说明受限原因，不显示不完整的资产统计。

## 边界

- 点击项目不会重新扫描目录。
- 不读取文件内容、Git 历史或知识库。
- 不调用 AI，也不生成项目目的、风险或建议。
- 不增加外部接口、云服务或用户项目写入。
- 项目详情随最新本机检查结果更新，不建立独立数据库。

## 后果

用户可以从项目集合自然进入单项目视图，并清楚区分“本机结构检查结果”和未来的 AI 项目理解。后续若要显示文件树、历史、关系或 AI 分析，必须由独立 Task 明确授权。
