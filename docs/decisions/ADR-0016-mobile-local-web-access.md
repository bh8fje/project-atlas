# ADR-0016：移动端本地 Web 访问

- 状态：Accepted
- 日期：2026-08-23
- 关联任务：TASK-017

## 背景

本地 Dashboard 需要在窄屏设备上保持可读和可导航，但 Project Atlas 仍坚持 Local First，当前阶段不应为移动查看引入公网中继、云同步、用户账号或原生应用维护成本。

## 决定

将现有 Dashboard 扩展为可安装的本地 Web App：提供标准 Manifest、移动 Viewport、安全区域适配、至少 44px 的触控目标、固定底部导航和移动摘要。访问地址与网络暴露范围继续由用户的本地运行环境决定。

不注册后台同步，不实现离线数据缓存，不创建远程访问隧道，也不加入身份认证。界面保持只读。

## 后果

- 手机浏览器可获得适合窄屏的查看体验，并可将 Atlas 添加到主屏幕。
- 安装元数据不改变数据边界；默认仍只有本地开发服务器。
- 如果未来需要跨设备远程访问，必须通过新的安全设计与独立 Task 决定。
- TASK-018 才会建立统一控制入口。
